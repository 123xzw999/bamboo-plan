## 它解决什么问题

长期目标失败，通常不是因为懒，而是因为**结构不清**：
「今年要提升自己」这种目标，没法执行，也没法复盘。
竹略强迫你把每件事一层层拆到「今天能动手」的颗粒度，同时保留它和顶层愿景的血缘关系。

层级不设上限：**总纲 → 领域 → 专项 → 任务 → 子任务 → ……**

## 功能

| 视图 | 做什么 |
| --- | --- |
| **总览** | 竹墨题、总体长势、各域分布、近期动态（改动自动记入日志） |
| **战略** | 树形无限下钻，编号 + 缩进导引；可增枝 / 修枝 / 上移下移 / 舍去，进度自下而上自动汇总 |
| **想法** | 随手落笺，之后把任意一笺「培育为枝」，挂到树上任意位置 |
| **分布** | 环形总览、各域实现条（已成 / 总数）、时间纵深（按期限排序） |

其它：期限与逾期提醒、明暗双主题（可跟随系统）、导出 / 导入 JSON 备份、响应式布局。

## 设计说明

**配色**：日间是宣纸米白 + 墨色，夜间是深墨竹青。
主色「翠墨绿」用于大标题，辅色「黑金」用于小标题与具体内容。

**艺术字**：大标题 / 标语用毛笔楷书（Ma Shan Zheng 子集化后自托管），
通过 `background-clip: text` + 渐变做出翠墨绿质感；
小标题用宋楷（ZCOOL XiaoWei 子集化）叠黑金渐变。

**竹影**：底部竹影是把一张水墨竹图**切成三段互相搭接**的窗口，
每段用不同周期 / 相位 / 幅度独立摆动 —— 整片竹林因此有层次地随风起伏，而不是整块平移。
亮色用白底墨竹、暗色用夜竹，出图时已把底抠成 alpha，所以能自然叠在任意底色上。
四个页面各用一景：春晓 · 劲竹 · 月影 · 盘根。

**无障碍**：尊重 `prefers-reduced-motion`（关掉全部动画）；`Esc` 关闭弹层；正文层级高于竹影。

## 素材与字体怎么来的

`tools/` 里是可复现的生成脚本（脚本期望同级的 `zhulue-source/` 目录：出图原稿与字体整包，
体积大，未随仓库发布）：

| 脚本 | 作用 |
| --- | --- |
| `make_bamboo.py` | 原图 → 缩到 1400px → 按亮度抠 alpha → WebP |
| `subset.py` | 扫描站点源文件用到的字，子集化字体（6.3MB 整包 → 94KB） |
| `verify.py` | 31 项端到端断言（门禁、四视图、增删改、双主题计算样式、持久化…） |
| `serve_inject.py` | 验收用的注入代理（预置登录态，并输出计算样式断言） |

```bash
python tools/make_bamboo.py
python tools/subset.py     # 改过静态文案后必须重跑
python tools/verify.py
```
